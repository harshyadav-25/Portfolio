Welcome to my personal portfolio website — a modern, responsive, and professionally designed platform that showcases my academic background, technical skills, projects, certifications, and career interests.

## Overview

This portfolio highlights my journey as a B.Tech Computer Science (AI & ML) student and aspiring software engineer. It presents my technical capabilities and professional goals through a streamlined, visually appealing interface that is easy to navigate and well-suited for recruiters and collaborators.

## Highlights

- Modern one-page portfolio layout with a sleek user experience
- Responsive design optimized for desktop and mobile devices
- Smooth animations and polished visual effects
- Dedicated sections for About Me, Skills, Projects, Certifications, and Contact
- Interactive navigation with active section highlighting
- Contact form with basic validation and user feedback

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Boxicons
- Typed.js

## Project Structure

- [index.html](index.html) — Main structure of the portfolio website
- [stylesheet.css](stylesheet.css) — Styling, layout, animations, and responsive design
- [main.js](main.js) — Interactive behavior including typing effects, scroll transitions, and form validation
- [pic.jpeg](pic.jpeg) — Profile image used in the portfolio

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/harsh-25/Portfolio.git
   ```
2. Open the project folder:
   ```bash
   cd Portfolio
   ```
3. Open [index.html](index.html) in your browser, or run it using a live server extension for a better development experience.
